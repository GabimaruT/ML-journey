# Types of Machine Learning

In this we are going to see the difference between AI, ML, and DL.

## Artificial Intelligence (AI)
AI is the broad field of creating machines that can perform tasks requiring human intelligence.

- Includes reasoning, planning, perception, and language understanding.
- Encompasses many techniques beyond learning.

## Machine Learning (ML)
ML is a subset of AI where systems learn patterns from data.

- The model improves automatically with experience.
- Includes supervised, unsupervised, and reinforcement learning.

## Deep Learning (DL)
DL is a subset of ML using large neural networks.

- Works well with images, audio, and text.
- Learns multiple layers of representation.

## Summary
- AI is the broad goal of intelligent systems.
- ML uses data to learn that intelligence.
- DL uses deep neural networks for complex patterns.
