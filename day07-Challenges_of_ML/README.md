# Challenges of Machine Learning

In this we are going to learn about challenges of ML.

Common challenges:
- **Getting enough good data:** ML models need quality data to learn well.
- **Handling noisy data:** Incorrect or inconsistent examples can hurt model performance.
- **Overfitting:** Models can learn the training data too well and fail on new data.
- **Underfitting:** Models may be too simple to capture important patterns.
- **Choosing the right model:** Different problems need different approaches.
- **Managing changing data:** Data can change over time, making models less accurate.

Why it matters:
- Solving these challenges helps create more reliable and useful ML systems.
- Understanding them helps you choose the right tools, data, and training process.

Summary: ML is powerful, but it requires careful data handling, good model design, and ongoing evaluation to work well.
