# Machine Learning Life Cycle

In this we are going to learn about the ML life cycle.

Key stages:
- **Problem definition:** Understand the task and goals.
- **Data collection:** Gather the data needed for training.
- **Data preparation:** Clean, format, and transform the data.
- **Model training:** Train a machine learning model on the prepared data.
- **Evaluation:** Measure how well the model performs.
- **Deployment:** Put the model into production use.
- **Monitoring:** Track model performance and update when needed.

Summary: the ML life cycle is the process of building, validating, deploying, and maintaining machine learning solutions.
